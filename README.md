# AQUA MOTIF GACHA

Splatoon系オリジナルキャラクターの水生生物モチーフを、iPhone Safariで10件ランダム抽選する静的Webアプリ。

- 現在候補: **1,304**
- 目標: **6,000**
- 1回10件、重複なし
- 説明・分類・タグは省略し、名前プールを高速拡張
- GitHub Pages向け

## Files
- `index.html` — UI
- `data/species-*.js` — 候補名の正本
- `app.js` — 抽選/コピー/前回保存
- `BATCH_PROGRESS.json` — 進捗
- `CHAT_HANDOFF.md` — ChatGPT/Codex引き継ぎ

## Codex
最初に `CHAT_HANDOFF.md` と `BATCH_PROGRESS.json` を読んでから作業すること。
